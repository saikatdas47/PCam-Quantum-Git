# Sources and reuse

PCam source: https://github.com/basveeling/pcam. Maintainers state that data are CC0 and repository code is MIT. Raw images are not redistributed here. Cite the original PCam and CAMELYON16 sources.

The original export contains pretrained ResNet50 weights identified as `resnet50.tv_in1k` and fitted scikit-learn/PyTorch states. The encoder is an external pretrained model, not a new architecture from this study. Preserve applicable upstream model and dataset terms. No new blanket license is assigned to external weights or data.

Scientific source snapshots, model bytes, predictions and test lock remain unchanged in the archive. Numbered analysis code adapts file locations while retaining the comparison and statistical definitions. Saved evidence checking is distinct from new training and independent investigator replication.
